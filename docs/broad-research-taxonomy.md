# Broad Research Taxonomy

## Objective

Keep the candidate universe broad. There is no strategic limit on the number of candidates we can discover. The system should expand by category, geography, language, platform, and source, while keeping every batch auditable.

## Core Categories

- Scientists
- Academics
- Artists
- YouTubers
- Podcasters
- Thought leaders
- Faith leaders
- Psychologists
- Therapists
- Doctors and medical educators
- Journalists
- Educators
- Technology voices

## Collection Rule

Discovery can be broad and uncapped, but it must run in batches:

- Each batch has source label and timestamp.
- Each candidate has source URLs.
- Contact routes remain blocked until official professional routes are verified.
- Suppression and opt-out checks override every score.
- Health and mental-health categories require extra review.
